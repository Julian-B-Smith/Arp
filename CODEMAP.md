# CODEMAP — Arp

Where things are. Update in the same change that moves them.

| Path | Role |
|---|---|
| `verify` | Oracle dispatcher (project-owned gates: private-name, structure, manifest, intake pin, spec pin, lab smoke, core suite) |
| `.kit/` | Kit-owned gates, vendored + sha256-pinned by `kit_sync.py` — never hand-edit |
| `.claude/` | Harness: settings (permissions), hooks (deny, dirty, stop gate), agents (critic, implementer, verifier), provenance skill |
| `intake/` | horde's packet (note vocabulary, engine note interface, quantizer, tempo divisions), read-only, pinned by `intake/MANIFEST` |
| `integrations/` | Inbound mailbox + outbound thread table |
| `docs/filings/` | Working copies of outbound filings |
| `docs/prior-art.md` | Phase 0 landscape, failure-mode rules, grid recipe, name check |
| `traces/` | One provenance entry per merged change |
| `spec/` | SPEC.md (RATIFIED, hash-pinned by `spec/MANIFEST`; errata in `docs/spec-errata.md`), params.json (settings + division ticks), bank/starter.json (step patterns as data) |
| `lab/arp-lab.html` | Single-file twin: CORE (pure; sliced by the smoke) / UI (adapter) banners |
| `tools/lab_smoke.mjs` | Headless lab smoke: SPEC §11 invariants with planted controls |
| `.claude/launch.json` | `lab` preview server (python http.server on localhost) |
| `index.html` | Root landing page: redirects to the lab, so the server's root is not a bare directory listing |
| `core/` | C++20 library, standard library only: `include/arp/` (core.h the interface, types.h events and settings, pattern.h step and pattern types, bank_data.h GENERATED by `tools/gen_bank.py`, int128.h / arith.h / draw.h the exact math), `src/core.cpp` |
| `tests/core/` | The invariant suite (`test_core.cpp` M1a, `test_m1b.cpp`, `test_m2a.cpp`, `test_m2b.cpp`, `test_m3.cpp` horde's bar rows, `test_evict.cpp`, `test_input.cpp`; `harness.h` sessions and `ARP_PLANTS` plants), built twice (native and two-word int128) plus a shipped-library smoke. `stream_digest*.txt` + `test_digest.cpp` + `digest_corpus.cpp`: the byte-identical reference (generated from the M3a core by `tools/core_digest.sh regen 0ef0903`). `test_random.cpp` (RN1, D-036) with `stream_digest_random*.txt`, cut from the first randomness core by `core_digest.sh regen-random ed943b2`. `render.cpp`: the listening renderer (`tools/render_listening.sh`, `lab/listen.html`). `bench.cpp`: the CPU/memory benchmark |
| `tools/core_test.sh` | Builds (Release, absolute paths) and runs the suite, plus the must-fail fast-math build check |
| `tools/core_params_check.py` | C++ defaults vs `spec/params.json`, compiled bank vs `spec/bank/starter.json`, each with a plant |
| `tools/core_bench.sh`, `tools/core_sanitize.sh`, `tools/core_digest.sh` | The Release benchmark (reported in `./verify full`), the suite under ASan/TSan/UBSan (CI), the digest regenerator |
| `docs/horde-copy-in.md` | The files horde copies, their sha256, build notes and the CPU envelope |
| `tools/gen_bank.py` | Generates `core/include/arp/bank_data.h` from the bank JSON (`--check` for drift) |
